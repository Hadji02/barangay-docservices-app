# Barangay San Rafael Document Services and Resident Records System

A web app for recording residents and the document requests (Barangay Clearance, Certificate of Residency, and others) that the barangay processes. It is built on the MySQL database designed in our Advanced Database Systems project.

## Folders
- `database/` : `schema.sql` (tables) and `seed.sql` (sample data)
- `docs/` : brief, CRUD map, sitemap, wireframes, style guide
- `prototype/` : static HTML and CSS pages

## How to load the database
1. Open HeidiSQL (Laragon) and connect.
2. Run `database/schema.sql`, then `database/seed.sql`.
